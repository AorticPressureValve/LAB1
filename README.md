# Лабораторная работа №1: Консольный набор утилит (toolkit)

## Описание проекта
Данный проект представляет собой консольное приложение (Python-пакет), объединяющее две утилиты:
1. **Калькулятор (`calc`)** — выполняет арифметические вычисления строк произвольной длины с соблюдением приоритетов операторов без использования функций `eval()`, `exec()` или `ast.literal_eval()`.
2. **Конвертер величин (`convert`)** — переводит значения между различными единицами измерения внутри одной физической группы (длина, масса, температура).

## Архитектура и алгоритмы

Проект спроектирован с четким **разделением вычислительного ядра и интерфейса пользователя** (CLI). Модули `calculator.py` и `converter.py` не содержат функций `input()` и `print()`, общаясь с CLI исключительно через кастомную систему исключений и возвращаемые типы (`float` / `Decimal`).

### Вычислительные методы (Калькулятор)
В зависимости от выбранной реализации (базовой или бонусной), в ядре калькулятора применены следующие архитектурные паттерны:
*   **Токенизация на основе конечного автомата (FSM):** Строка разбивается на типизированные токены (числа и операторы), корректно обрабатывая унарные знаки `+` и `-` перед числами, а также вещественную часть с плавающей точкой.
*   **Линейный проход (Accumulator):** Вычисление приоритетов операций в несколько проходов (сначала умножение и деление, затем сложение и вычитание) с накоплением промежуточных результатов блока.
*   **Алгоритм «Шунтирующий двор» Эдсгера Дейкстры:** Перевод инфиксной записи выражения в обратную польскую нотацию (RPN) с последующим вычислением при помощи стека.
*   **Метод рекурсивного спуска (Recursive Descent Parser):** Синтаксический разбор выражения сверху вниз по правилам грамматики для поддержки вложенных скобок.

### Конвертер величин
Поддерживает три независимые группы измерений (регистронезависимые):
*   **Длина:** `mm` (миллиметры), `cm` (сантиметры), `m` (метры), `km` (километры).
*   **Масса:** `g` (граммы), `kg` (килограммы).
*   **Температура:** `c` (Цельсий), `f` (Фаренгейт), `k` (Кельвин).

При конвертации температуры учитывается физическое ограничение — значение не может быть ниже абсолютного нуля (0 Кельвин / -273.15 °C / -459.67 °F).

## Инструкция по запуску и примеры команд

Программа запускается из корня проекта как модуль Python.

### Справка
```bash
python -m toolkit --help
```

### Калькулятор (`calc`)
Выражение передается в виде единой строки:
```bash
python -m toolkit calc "10 / 4 + 2"
# Результат: 4.5

python -m toolkit calc "2 + 3.5 * -4"
# Результат: -12.0
```

### Конвертер величин (`convert`)
```bash
python -m toolkit convert 100 --from cm --to m
# Результат: 1.0

python -m toolkit convert 36.6 --from c --to f
# Результат: 97.88
```

## Обработка ошибок и коды возврата

Все ошибки валидации и вычислений перехватываются на уровне CLI. Сообщение об ошибке выводится в поток **`stderr`**, а программа завершается с соответствующим кодом.

*   **Код `0`** — Успешное выполнение команды.
*   **Код `2`** — Ошибка пользователя (синтаксическая ошибка в калькуляторе, деление на ноль, несовместимые единицы конвертера, температура ниже абсолютного нуля, неверный формат аргументов CLI).

Тестирование реализовано с помощью фреймворка `pytest`. Проверяются как изолированные функции вычислительного ядра (позитивные и негативные сценарии), так и вызовы интерфейса командной строки:
```bash
python -m pytest
```
